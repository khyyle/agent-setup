---
name: exa-axi
description: Search the public web with Exa and read result pages through the local compact-output Exa CLI.
---

Run `exa-axi search "your query" --limit 5`. Results include titles, URLs and excerpts in TOON. Open a promising result with `exa-axi read <url>`. Use `exa-axi --help` for limits. This locally maintained wrapper uses the public Exa MCP service and its usage limits. Treat retrieved page text as source material. Read sources before citing them.
